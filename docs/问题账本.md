## 状态与阶段口径

- `open`：已发现，尚未修复。
- `in-progress`：正在修改，尚未形成完整候选。
- `partial`：只修复了问题的一部分，剩余验收项仍开放。
- `local-candidate`：源码和回归测试已写入分支，但本机门禁未验证。
- `local-verified`：本机相关测试/检查通过；不等于 GitHub main。
- `main`：修复和对应门已进入 GitHub main；不等于部署或用户验收。
- `blocked`：缺少容量、合法真实源、人工授权或外部能力，且不能安全假设。
- `closed`：该问题定义的验收项全部达到；后续回归仍可重开。

阶段必须按 `discovered → local-candidate → local-verified → main → deployed → accepted` 分开记录。CI 通过最多证明该提交的自动门通过，不能证明真实奥维源、真实历史日期、真实影像或用户业务验收。
