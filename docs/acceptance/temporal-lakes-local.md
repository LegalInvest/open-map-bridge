## AOI 与环境结论

- 通用非预设 AOI 的创建、服务端身份、确认版本、自动四期与四屏加载已由 Chrome E2E 验证。
- 宝应湖和高邮湖两个预设均来自用户参考图的近似人工转译，状态仍为 `approximate`；尚无用户在真实底图上的精确湖界确认，因此湖区事实型 AC-012/013 未接受。
- 尚未得到真实 20 年影像，也没有水质、养殖围网、岸线审批或现场记录的逐年对齐；当前没有“污染/过度开发/过度渔猎”的事实结论。
