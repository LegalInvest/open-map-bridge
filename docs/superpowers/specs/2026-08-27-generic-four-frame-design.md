# OpenMapBridge 通用框选四期历史影像设计

## 状态

- 状态：Approved / Implementing
- 用户裁决：2026-08-27 明确回复“按 A 执行”
- 产品真值：项目根目录 `goal.md`
- 现实与证据：项目根目录 `research.md`
- 替代关系：本设计把“双湖固定入口”收敛为“任意框选区域”；宝应湖和高邮湖保留为示例与回归夹具

## 1. 当前只解决的用户问题

用户已经在奥维官方客户端导入一张有权使用的历史影像二维码。用户要在任意地图位置框选矩形或多边形，系统自动覆盖最近 20 个完整自然年，并选择四个尽量等距的真实可请求时间点，在同一范围、投影、中心、缩放和旋转下显示四张影像。

本切片的成功不是“页面存在”“合成瓦片通过”或“奥维中出现时间轴”，而是：一个非预设区域通过已授权奥维历史源返回至少两个、目标为四个可解码且内容不同的真实影像帧；每帧显示请求日期、拍摄日期或未知、加载事实和来源。

## 2. 用户旅程

1. 用户打开“历史影像四期对比”。
2. 选择已注册图源；默认优先本机已授权源，合成源明确标为开发验收源。
3. 点击“新建框选区域”，在地图上选择矩形或多边形并输入名称。
4. 点击“使用此范围”。网关验证 EPSG:4326 GeoJSON，生成稳定区域 ID、版本 1 和确认时间。
5. 系统按当前日期计算最近 20 个完整自然年。例如 2026 年运行时为 2006-01-01 至 2025-12-31。
6. 系统取得源的日期目录，并围绕起点、三分之一、三分之二和终点四个锚点选择最近可请求日期。`available` 优先于 `unknown`；`missing/failed` 不自动入选四期。
7. 四屏只请求当前可见瓦片。任一屏失败只影响该屏；其他屏保持可用。
8. 用户平移、缩放或旋转任一屏，其他屏同步。刷新后已保存区域仍可选择。

## 3. 日期规则

### 最近 20 个完整自然年

```text
toYear = 当前 UTC 年 - 1
fromYear = toYear - 19
```

默认使用完整自然年，避免把尚未结束的当前年当成完整年度。用户后续可以增加自定义窗口，但不属于当前切片。

### 四期自动选择

1. 对 `[fromYear, toYear]` 建立四个等距锚点，包含首尾。
2. 候选先取 `available`；不足四个时补 `unknown`，因为奥维官方桥接可能只能按请求日返回，不能事先列出真实可用性。
3. 每个锚点选择尚未使用且距离最近的候选；距离相同时选更早日期，保证确定性。
4. 候选少于四个时不得复制同一帧冒充四期；UI 显示实际可比较期数和缺口。
5. `requestDate`、`captureDate` 与 `availability` 始终分开。官方桥接不返回拍摄日期时显示“拍摄日期未知”。

## 4. 区域规则

- 核心模型继续使用版本化 `AreaOfInterest`，ID 不再枚举湖泊。
- `POST /api/aois` 创建用户框选区域；客户端不能指定服务器 ID、版本、确认时间或 provenance。
- 网关生成 ID，验证闭合、经纬度范围、顶点上限和自交，再以 `confirmed` 版本 1 保存。
- `PUT /api/aois/:id` 继续用于编辑既有区域并追加版本。
- 地图初始视角通过几何 extent 自适应，不得再按 `baoying-lake`/`gaoyou-lake` 写死 zoom。
- 双湖预设仍可直接选择，但不会获得任何核心特权。

## 5. 架构

```text
奥维官方客户端（用户已授权图源）
        │ 官方本机 Web 瓦片接口，仅回环
        ▼
OviBridgeAdapter ─┐
SyntheticAdapter ─┼─ TemporalSourceAdapter
标准开放源（后续）─┘
        │ listDates / tile / probe
        ▼
Fastify Gateway
  ├─ AOI 创建与版本化
  ├─ 20 年窗口与四期选择契约
  ├─ 已注册源专用瓦片路由
  └─ 小型状态与脱敏回执
        ▼
OpenLayers Web
  ├─ 矩形/多边形框选
  ├─ 四屏统一 ViewState
  ├─ 日期与加载事实
  └─ 双湖仅作为示例
```

腾讯云 `satmap-web` 后续可作为项目汇报、PPT 和调研结果消费端；它不进入本切片的图源、日期或瓦片核心。

## 6. 安全与资源边界

- 奥维兼容只调用官方客户端已经授权的本机接口，不破解 GEE 认证、会员或设备绑定。
- 第三方接口启用后立即检查 socket；只接受 `127.0.0.1`/`::1`。监听 `0.0.0.0`、`*` 或局域网地址时立即关闭。
- 浏览器不能提交上游 URL、host、token 或 mapType；这些只来自本机进程配置。
- 不批量下载 20 年整域瓦片；四屏按当前视口加载。
- 可用空间低于 8 GiB 停止构建、测试、截图和新增缓存。
- 不保存用户二维码、真实瓦片、源站秘密或完整探针响应。

## 7. 当前验收

### 自动验收

- `POST /api/aois` 对合法任意多边形生成确认区域，对自交/越界/客户端伪造字段失败关闭。
- 最近 20 个完整自然年计算在年界稳定。
- 四期选择对 available、unknown、missing 和不足四期行为确定且不复制。
- MapPane、SwipeCompare、AOI 编辑/创建均按几何 extent 自适应，不依赖湖泊 ID。
- 浏览器从“新建框选区域”创建一个非湖区 AOI，自动得到四期并显示四屏。

### 真实源验收

- 官方奥维接口只监听回环。
- 已授权历史源对同一 AOI 的至少两个请求日期返回可解码、非空、归一化哈希不同的影像；目标为自动四期全部加载。
- HTTP 200、同一占位图重复四次、合成瓦片或官方客户端时间轴均不算通过。

## 8. 后续扩展顺序

当前闭环通过后，再按同一 `TemporalSourceAdapter` 增加 XYZ/TMS、WMTS、WMS、ArcGIS REST、STAC/COG、`.ovmap` 版本适配、区域缓存、任务队列和视频导出。任何“奥维全部能力”都必须拆成可核验协议矩阵；不存在一个未经样本和许可证核验即可宣称全兼容的开源仓库。
